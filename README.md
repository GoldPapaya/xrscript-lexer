# xrscript-lexer (in progress)
I am working towards making a compiler for a new language called xrscript (name subject to change because 'xrscript' is awfully boring), written in Golang. Specifics haven't really been established yet but will be settled as the project develops. I did however establish a formal grammar which this language follows, and will probably grow it to include other features later. Also this repo will be for a lexer, but may evolve to eventually include other components needed to make the compiler.
